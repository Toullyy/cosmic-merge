# Cosmic Merge (prototype)

เกมรวมดาว แนวตั้ง เล่นต่อเนื่อง ทำเป็น PWA ด้วย Phaser 3 (Matter physics)

## วิธีรัน

PWA และ service worker ต้องเปิดผ่านเซิร์ฟเวอร์ ไม่ใช่ดับเบิลคลิกไฟล์:

```bash
cd merge-game
python3 -m http.server 8080
# เปิด http://localhost:8080 (ลองด้วยโหมดมือถือใน DevTools)
```

เกมโหลด Phaser จาก CDN (jsDelivr) ถ้าอยากให้ทำงานออฟไลน์ตั้งแต่ครั้งแรก
ให้ดาวน์โหลด `phaser.min.js` (เวอร์ชัน 3.80.1) มาวางในโฟลเดอร์นี้ เกมจะใช้ไฟล์นั้นก่อน

## ไฟล์

| ไฟล์ | หน้าที่ |
|---|---|
| `game.js` | ตัวเกมทั้งหมด (ฟิสิกส์, การรวมดาว, คะแนน, จบเกม) |
| `ads.js` | ชั้นโฆษณา เปลี่ยนเจ้าของโฆษณาแก้ที่ไฟล์นี้ไฟล์เดียว |
| `sw.js` | service worker (เล่นออฟไลน์) เปลี่ยนเลข `CACHE` ทุกครั้งที่อัปเดตเกม |
| `manifest.json` | ตั้งค่า PWA (`orientation: portrait`) |

## ปรับสมดุลเกม (ต้นไฟล์ `game.js`)

- `LEVELS` รัศมีและสีของดาวแต่ละระดับ
- `POOL` ดาวที่สุ่มให้ทิ้ง
- `DANGER`, `SETTLE_MS`, `OVER_MS` เส้นอันตรายและเวลาที่ให้ก่อนแพ้
- `CLEAR_*`, `CONTINUE_CLEAR` ความแรงของรางวัลจากการดูโฆษณา

## โฆษณา

ตอนนี้ใช้ `provider: 'mock'` (โฆษณาจำลอง ไม่มีรายได้) ใน `ads.js`
- **Rewarded:** ปุ่ม "ล้างกอง" และ "เล่นต่อ" หลังจบเกม
- **Interstitial:** ตอนกดเล่นใหม่ ไม่ขึ้นใน 2 เกมแรก และเว้นอย่างน้อย 90 วินาที

เมื่อได้รับอนุมัติ AdSense for Games ให้เปลี่ยน `provider` เป็น `'adsense'`
ใส่ `adsenseClient` ของตัวเอง และปิด `testMode` ก่อนขึ้นจริง
ถ้าส่งเกมเข้าพอร์ทัล (Poki, CrazyGames ฯลฯ) ให้ใช้ SDK ของพอร์ทัลนั้นแทน โดยแก้เฉพาะ `ads.js`
